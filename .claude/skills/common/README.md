# Common references

Shared, progressive-disclosure material for every skill in `doddle-social-media-skills`.
Skills link here instead of repeating themselves.

| File | Use it for |
|------|-----------|
| `response-contract.md` | The canonical 4-part output order and hard rules |
| `data-reliability.md` | Source precedence, null handling, no-fabrication rules |
| `fundamentals.md` | Social concepts, the four pillars, metric vocabulary |
| `scoring-methodology.md` | Post and account signals, weights, tier bands, versioning |
| `platform-specs.md` | How to read the platform-spec registry (limits/ratios/durations) |
| `mcp-integration-guide.md` | The tool-ID registry and fallbacks |

## The rule that ties them together

The toolkit computes; the model narrates. Every number is reproducible from recorded evidence.
If a skill cannot point to a source for a figure, it does not report that figure.
